# Standards

Rules the team follows when changing the Doctor Food website. Read the document that matches your task before you start.

| Document | Read it when you... |
|---|---|
| [FRONTEND_STANDARDS.md](FRONTEND_STANDARDS.md) | build or change a component, page, layout, style or text |
| [I18N_CONTENT_GUIDE.md](I18N_CONTENT_GUIDE.md) | add or translate any text in `messages/*.json`, or write localized titles and descriptions |
| [BLOG_WRITING.md](BLOG_WRITING.md) | write or edit a blog post in `content/blog/` |

If two documents disagree, the more specific one wins: a blog post follows `BLOG_WRITING.md`, and the claims rules in `I18N_CONTENT_GUIDE.md` apply to every page.
